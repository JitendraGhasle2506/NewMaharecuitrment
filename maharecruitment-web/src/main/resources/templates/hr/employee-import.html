Maximum 3,000 employee rows per CSV file. For multiple location IDs, use pipe format like 1|2|3.
Required Columns
  • recruitmentType - INTERNAL or EXTERNAL
  • fullName
  • email
  • mobile
  • joiningDate - prefer yyyy-MM-dd
  • onboardingDate - prefer yyyy-MM-dd
  • agencyId - mandatory for INTERNAL and EXTERNAL
Optional Columns
  • employeeCode - blank generates MahaI + Aadhaar last 4; without Aadhaar uses EMP sequence
  • dateOfBirth - blank uses 1900-01-01
  • gender - blank uses NOT_SPECIFIED
  • bloodGroup - blank uses NA
  • address - blank uses NOT_PROVIDED
  • emergencyContactName - blank uses NOT_PROVIDED
  • emergencyContactRelation - blank uses NOT_PROVIDED
  • emergencyContactMobile - blank uses employee mobile
  • panNumber - blank uses NOT_PROVIDED
  • aadhaarNumber - blank skips API attendance sync for that employee
  • departmentRegistrationId
  • subDepartmentId
  • subDepartmentName - used when subDepartmentId is blank; resolves employee department automatically
  • designationId
  • levelCode
  • requestId
  • status - default ACTIVE
  • locationIds - example 1|2
